# Websites

Static marketing sites for the panda and tastybamboo brands.
These are interim — the plan is to migrate them into panda-cms
once the content and design are finalised.

## Folder Structure

| Folder | URL | Purpose |
|--------|-----|---------|
| `pandacms.io/` | pandacms.io | Panda CMS product site — docs, features, getting started |
| `tastybamboo.net/` | tastybamboo.net | Tastybamboo company site — about, pricing, pro features |

## Key Principles

- Both sites use UK English
- Follow brand guidelines in `../brand/`
- Copy should align with `../marketing/` positioning
- All pages need proper OG tags for social sharing
- Mobile-first responsive design
