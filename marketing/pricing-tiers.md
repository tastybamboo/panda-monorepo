# Panda Pro — Pricing Tiers

## Model

tastybamboo sells **panda-pro** as a single paid gem with bundled tiers.
Each tier unlocks additional features across the entire panda ecosystem.
The open-source gems (panda-core, panda-cms, panda-editor) are always free.

## Tiers

### Community (Free)

**Target:** Open-source users, hobby projects, evaluators

| Gem | Included |
|-----|----------|
| panda-core | Full — authentication, admin UI, components, navigation |
| panda-cms | Full — pages, posts, templates, menus, forms, media |
| panda-editor | Full — EditorJS rich text editing, footnotes, embeds |
| panda-website-users | Full — front-end user auth, registration, OAuth |

### Starter

**Target:** Small sites, freelancers, solo developers

Everything in Community, plus:

| Feature | Source Gem |
|---------|-----------|
| AI content generation (SEO, alt text) | panda-pro |
| Content versioning & change tracking | panda-pro |
| Basic analytics dashboard | panda-pro |
| Provider configuration (AI, email, storage) | panda-pro |
| Settings management | panda-pro |
| MCP server (AI agent integration) | panda-pro |

### Business

**Target:** Growing organisations, agencies, multi-site operators

Everything in Starter, plus:

| Feature | Source Gem |
|---------|-----------|
| Community forums | panda-community |
| Newsletter campaigns | panda-newsletters |
| Advanced analytics | panda-pro |
| Roles & permissions (RBAC) | panda-pro |
| Content workflow (draft/review/publish) | panda-pro |
| API access | panda-pro |

### Enterprise

**Target:** Large organisations, custom requirements

Everything in Business, plus:

| Feature | Source Gem |
|---------|-----------|
| Helpdesk & ticketing | panda-helpdesk |
| Custom SLAs | tastybamboo support |
| Priority support | tastybamboo support |
| Custom integrations | tastybamboo consulting |
